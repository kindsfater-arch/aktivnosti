# Активности

Веб-сервис для учёта активностей и сделок по эквайрингу (МПП, МПС, МРГК, НУ). Данные хранятся в Google-таблице «активности», сервер работает на Google Apps Script, код лежит на GitHub и публикуется оттуда автоматически.

## Что умеет

- **План:** просроченные шаги, сегодня, неделя, следующая неделя, клиенты в работе без следующего шага.
- **Ввод активности:** по ИНН подставляются краткое и полное название (ФНС), потенциал (оборот у конкурентов из PS), оборот в Сбере, история и сведения о том, у кого клиент уже в работе.
- **Проверки:** дата активности и приоритет клиента (ключевой / неключевой) обязательны. Приоритет подставляется из последней активности по клиенту или из файла продаж — его нужно проверить. Вид активности, канал и статус выбираются из списков. Комментарий с сутью активности обязателен. Для статусов с типом «Сделка» обязательна сумма сделки. Выбрать можно только статусы, отмеченные в справочнике как доступные; снятые с выбора остаются в старых записях и отчётах, и у старой записи такой статус можно оставить при правке.
- **Активности:** журнал с фильтрами по периоду, сотруднику, статусу, виду, каналу и поиску. Первая строка таблицы — итоги по всем отобранным записям: число активностей и дней, сотрудники, клиенты (из них ключевые), разбивка по видам, статусам и каналам, потенциал по клиентам (из последней активности за период), сумма и число сделок, назначенные следующие шаги.
- **Сделки:** воронка по месяцу следующего шага с потенциалом и заключённые сделки по месяцам.
- **Лиды PS:** крупные клиенты конкурентов, по которым ещё никто не работает. Кнопка «В работу» создаёт первую активность.
- **Выполнение плана:** видят все сотрудники. За выбранный месяц по каждому сотруднику и по команде: продажи (шт — из файла продаж по дате регистрации) и объём (₽ — по суммам сделок в активностях) — план, факт, исполнение, прогноз по RR (факт ÷ прошедшие рабочие дни × все рабочие дни месяца) и справочно сколько осталось до плана и сколько это в рабочий день. Планы задают администратор и начальник отдела кнопкой «Задать планы».
- **Отчёты** (для тех, у кого есть доступ): активность сотрудников за период по видам и статусам. Одна кнопка «Выгрузить в Excel» за день, неделю, месяц, период или всё время. Внутри сводка, все разрезы (сотрудник, НО, тип сотрудника, канал, статус, вид активности, дни), просроченные шаги, активности и текущее состояние клиентов. Файл собирается прямо в браузере, без создания файлов на Google Drive.
- **Админка:** пользователи, роли, персональные ссылки, справочники, обновление оборотов.

## Права

| Роль | Видит | Отчёты и выгрузка |
|---|---|---|
| Сотрудник | свои активности (по ФИО) и сотрудников, которых ему открыл администратор | если включён флажок «Доступ к выгрузке отчётов» |
| Начальник отдела | всё | если включён флажок «Доступ к выгрузке отчётов» |
| Администратор | всё, плюс управление пользователями и справочниками | да |

Вход — по персональной ссылке вида `…?k=<ключ>`. Ссылку выдаёт администратор. Если её переслали, администратор нажимает «Выдать новую ссылку», и старая перестаёт работать. Саму Google-таблицу сотрудникам **не открывайте**: фильтрация по правам выполняется на сервере.

## Данные

| Что | Откуда | Как считается |
|---|---|---|
| Потенциал оборота в мес | последний `PS_xx.xlsx` | сумма `vol` по всем строкам ИНН, то есть оборот клиента у банков-конкурентов. Можно поправить вручную, тогда импорт значение не перезаписывает |
| Оборот в Сбере (только справочно, в карточке ИНН) | последний `PL_xx.xlsx`, если его нет — `US_xx.xlsx` | колонка «Оборот» (= US + NON-US) |
| Названия ЮЛ | DaData (ключ в «Админ → Настройки»), уже введённые активности | ИНН, найденный однажды, сохраняется на листе «Компании» и повторно не ищется. ФНС не используется: она недоступна с серверов Google |

Фактические продажи загружаются каждый день в 7:00 из таблицы продаж (`APP.SALES_SHEET_ID`, строка — одна продажа) на лист «Продажи», вручную — кнопкой в админке. Месяцы, которые есть в источнике, заменяются целиком, прошлые сохраняются.

Обороты обновляются каждый день в 6:00 (по калининградскому времени), если в папке появился новый файл, и вручную кнопкой в админке.

## Структура

```
apps-script/          код Apps Script (выкладывается через clasp)
  Config.gs           константы: ID таблицы и папки, колонки, справочники по умолчанию
  Setup.gs            setup() — первичная настройка таблицы, пользователей, триггера
  Api.gs              doGet / doPost / api — веб-приложение и маршруты API
  Users.gs            роли, персональные ссылки
  Activities.gs       журнал активностей, проверки, права
  Views.gs            план, сделки, лиды
  Import.gs           импорт PS / PL / US
  Companies.gs        названия по ИНН
  Reports.gs          отчёты
  Plans.gs            планы на месяц (лист «Планы») и их выполнение
  Sales.gs            загрузка фактических продаж (лист «Продажи»)
  Index.html          интерфейс
scripts/build-web.sh  сборка интерфейса для GitHub Pages
.github/workflows/    автодеплой при push в main
```

## Первый запуск

### 1. Apps Script

Все действия выполняются под Google-аккаунтом владельца таблицы и папки с оборотами.

1. Включите Apps Script API: <https://script.google.com/home/usersettings>.
2. Установите clasp и войдите:
   ```bash
   npm install -g @google/clasp@2.4.2
   clasp login
   ```
3. Создайте проект и загрузите код. Команды выполняются из корня репозитория:
   ```bash
   clasp create --type standalone --title "Активности" --rootDir apps-script
   git checkout apps-script/appsscript.json   # clasp create перезаписывает манифест
   clasp push -f
   ```
4. Разверните веб-приложение:
   ```bash
   clasp deploy -d "v1"
   ```
   Команда выведет ID развёртывания (`AKfy…`). Адрес сервиса: `https://script.google.com/macros/s/<ID>/exec`.
5. Пропишите адрес из шага 4 в `APP.WEB_APP_URL` в `Config.gs` и снова выполните `clasp push -f` и `clasp deploy -i <ID>`. Свойство скрипта `APP_URL` имеет приоритет.
6. Откройте редактор командой `clasp open`.
   1. Запустите функцию `setup` и разрешите доступ. При предупреждении «Приложение не проверено» нажмите «Дополнительно → Перейти».
   2. Запустите `importTurnovers` — это первая загрузка оборотов.
   3. Запустите `refreshLinks`. В журнале выполнения появятся персональные ссылки.
7. Откройте свою ссылку администратора. Во вкладке «Админ» заведите сотрудников и раздайте им ссылки.

`setup()` переименует «Лист1» в «Активности» и добавит служебные колонки M–S: сумма сделки, ID, источник потенциала, автор, даты. Он также создаст листы «Пользователи», «Справочники», «Обороты», «Компании», «Журнал» и выпадающие списки. Администратором становится ФИО из `APP.ADMIN_FIO` в `Config.gs`. ФИО, уже записанные в таблице, заводятся как сотрудники и начальники отделов.

### 2. GitHub

1. Создайте репозиторий (лучше приватный) и отправьте в него код:
   ```bash
   git remote add origin git@github.com:<user>/<repo>.git
   git push -u origin main
   ```
2. В репозитории откройте Settings → Secrets and variables → Actions:
   - секрет `CLASPRC_JSON` — содержимое файла `~/.clasprc.json`, который появился после `clasp login`;
   - переменная `SCRIPT_ID` — `scriptId` из `.clasp.json`;
   - переменная `DEPLOYMENT_ID` — ID из шага 4.

   После этого каждый push в `main` обновляет код Apps Script и веб-приложение по тому же адресу.
3. Необязательно — интерфейс на GitHub Pages, без плашки Google сверху:
   1. Включите Settings → Pages → Source: GitHub Actions. Для приватного репозитория нужен платный план GitHub, для публичного — бесплатно. В репозитории только код, данных нет.
   2. Добавьте переменную `API_URL` — адрес `…/exec` из шага 4.
   3. После публикации укажите адрес страницы Pages в «Админ → Настройки → Адрес интерфейса». Персональные ссылки обновятся.

## Ограничения

- Квоты Apps Script для личного аккаунта: 6 минут на запуск, 20 000 внешних запросов в день. Импорт PS на 8 МБ укладывается.
- Названия по ИНН подставляются только при заданном ключе DaData. Бесплатный тариф даёт 10 000 запросов в день, ключ выдаётся после регистрации.
- Обороты клиентов составляют банковскую тайну. Размещение этих данных на личном Google Drive нужно согласовать с требованиями ИБ.
